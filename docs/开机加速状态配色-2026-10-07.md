# 开机加速整行状态配色

用户希望启用、禁用的区别更明显，并用颜色区分整行任务。

## 交互

- 启用：浅绿色整行背景、绿色左侧标识及状态标签。
- 禁用/服务非自动：浅灰蓝整行背景、灰色左侧标识及状态标签。
- 禁用/改为手动按钮为橙色；启用/设为自动按钮为绿色。
- 鼠标悬停或选中使用边框提示，选中后仍保留状态背景。
- 状态文字及图例始终存在；颜色表示启动状态，不代表安全等级或禁用建议。
- 禁用/启用后以及失败/取消恢复时，整行、按钮和标签随 Enabled 属性一起更新，沿用原操作流程。
