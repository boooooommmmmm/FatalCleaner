# 开机加速：明确显示禁用按钮

用户反馈在开机加速页找不到禁用按钮。v0.23.0 原界面使用“启用”列中的复选框切换状态，只有存在建议项时才显示批量禁用按钮，单项操作不够直观。

## 改动

- 列表第一列显示“禁用／启用”按钮，第二列独立显示状态；无推荐项时也能看到单项按钮。
- 服务操作明确显示“改为手动／设为自动”，继续经过现有确认、备份及还原点流程。
- 不支持切换的项目保留灰色按钮并提供原因提示；扫描或操作忙碌时暂停按钮交互。
- 操作走原 ToggleRequested 处理流程，失败/取消回写状态时同步按钮文字。
- 工具栏改为可换行布局，统计另起一行，避免窄窗口重叠；列表允许横向滚动查看更多列。

## 验证与交付

- Release App 测试 **128 项通过**，含 4 项新增回归：两种宽度下无建议项仍显示单项操作、忙碌禁用、受限项说明、服务文案与状态恢复。
- Debug 构建零警告、零错误。Core 无改动，本轮未重跑 Core 测试。
- WPF 使用测试数据渲染页面，未实际修改系统启动项或服务。
- 证据：`artifacts/verification/startup-action-2026-10-07/`，截图位于 screenshots。
- 本地独立预览包：`publish/startup-action-preview/CleanSweep.exe`。它使用当前工作区，公开 v0.23.0 包保持原状。
- 未提交、推送或发布新版本。
