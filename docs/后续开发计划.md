已确认 NuGet 依赖清理造成 Unity 构建中断，详见[事故记录与防护](NuGet依赖误清理事故与防护-2026-10-08.md)。v0.25.0 已发布依赖路径保护、开发缓存默认确认与每次重新勾选、旧扫描结果阻断、隔离区自动淘汰保留及回归测试；两轮发现的缺失依赖已还原并核对。使用旧 EXE 时仍需升级才能获得保护。任意工具自定义仓库发现、真实多用户验证仍待补充。

### 前两批功能

已按[清理扩展与本地空间盘点](清理扩展与本地空间盘点-2026-10-08.md)完成前两批，详情与验证见[当前状态](当前状态.md)。

1. JetBrains 开发者缓存：移除整根目录指纹缓存，增加旧指纹兼容防护；开发者页复用应用缓存页的专用规则、风险级别和时间门槛，保留 Local History。
2. .NET 构建产物首版：在用户指定项目中读取项目文件、project.assets.json 与 FileListAbsolute 生成清单，只预览 bin/obj 中明确列出的生成文件；默认确认、逐文件隔离，执行前复核当前项目范围、依据与进程。保护源码、配置、未知文件、白名单和目录链接。

首版构建文件及生成清单至少 24 小时未修改；发现 dotnet/MSBuild/编译或测试服务/Visual Studio/Rider 时保守跳过，页面说明原因。自定义输出路径、没有有效生成清单及同目录多个项目暂不支持。Release Core 579 + App 128 = 707 项通过，零警告/错误，数据签名通过；未发布、未执行用户本机候选目录清理。

### 第二批：程序更新缓存管理（已完成）

设置 → 更新与记录 → 程序更新缓存，可预览并勾选超过 7 天的已过期签名更新包、下载片段及失效索引，复核后移入隔离区。保留待安装/较新包、未知文件与恢复目录；与下载及索引读写共用文件锁。

第二批完成时验证为 **Core 596 + App 133 = 729 项通过**，零警告/错误，签名校验通过。本批新增 22 项回归；尚未发布，未清理真实用户缓存。后续依赖误清理防护完成后，全量验证为 **Core 631 + App 136 = 767 项通过**，新增 38 项回归，详见[当前状态](当前状态.md)。

## 配套验收

真实 Windows 权限与升级验收应与功能开发并行规划：普通用户、另一管理员凭据、SYSTEM 服务、多用户、服务运行中升级、权限拒绝、文件占用、空间不足和中断恢复。环境、版本、产物哈希及实际结果必须记录，普通单元测试通过不替代这些结果。

当前代码签名状态与其他限制见[当前状态](当前状态.md)。
