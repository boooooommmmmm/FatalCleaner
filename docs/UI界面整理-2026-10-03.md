# UI 界面整理

日期：2026-10-03。本地已实现并验证，尚未提交或发布，公开版本仍为 v0.22.0。

## 本轮调整

### 统一视觉层级

- 使用深蓝文字、青绿强调色、浅灰蓝背景和白色卡片；风险颜色保持独立。
- 17 个功能页显式使用共享页面样式，统一字体、字号、背景和正文颜色。
- 页面标题 28px，常规正文 13px；辅助说明使用较淡文字，主操作使用实色按钮。
- 统一卡片和按钮圆角、边框、输入框焦点反馈、列表表头和行间距。
- 修正按钮文字的颜色继承，确保主按钮上的文字为白色；标签选中样式只作用于标签标题。
- 滚动条改为细轨道，保留滚轮、拖动和横纵分页操作；确定进度使用实心条，避免无关的主题动画。

### 导航和首页

- 默认窗口调整为 1240 × 800，最小窗口仍为 960 × 600；侧栏 212px，内容区设置最大宽度。
- 增加品牌标识，当前导航项以浅青底、侧边标记和强调色显示，保留可折叠分组与底部固定入口。
- 首页保留渐变主操作区、完整优化动画和处理范围；开始前收起没有结果的四张数字卡，取得结果后展示。
- 清理范围、风险提示、隔离区入口与实际收益区分继续可见。

### 设置页

将原来的长列表分成三类，每类独立滚动：

| 分类 | 内容 |
| --- | --- |
| 常规与清理 | 高级模式、隔离保留期、卸载监控、残留扫描、开发者项目目录 |
| 备份与白名单 | 系统还原点、注册表与任务备份、目录白名单、已忽略项目 |
| 更新与记录 | 程序更新、规则更新、清理历史与操作日志 |

程序更新单独成卡并置顶，检查、取消、安装和下载进度集中展示。规则库的更新来源与较长校验说明默认折叠。右侧操作和标题分配独立空间，长路径为操作按钮留出位置。

### 内存与进程

将拥挤的左右两栏改成“运行中的进程 / 后台运行权限”两个标签。进程表格使用完整内容宽度，保留横向滚动，窄窗口仍能到达右侧操作；顶部内存概览始终保留。
