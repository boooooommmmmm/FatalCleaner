# FatalCleaner v0.23.0

CleanSweep 正式更名为 **FatalCleaner**，GitHub 仓库同步更名为 `boooooommmmmm/FatalCleaner`。

## 新品牌与图标

- 主窗口、侧栏、更新提示、程序属性及导出文件名使用 FatalCleaner。
- 使用全新的硬盘与扫帚图标，支持 Windows 多种图标尺寸，应用于程序、窗口和侧栏。
- 发布包更名为 `FatalCleaner-win-x64-0.23.0.zip`。

## 界面整理

- 统一导航、按钮、卡片、输入框和表格样式，页面布局更清晰。
- 设置页分为“常规与清理”“备份与白名单”“更新与记录”，程序更新独立展示。
- 内存页分为“运行中的进程”和“后台运行权限”，进程列表获得完整宽度。
- 一键优化首页在处理完成后再展示结果卡，减少初始页面的信息干扰。

## 一键优化动画

- 增加完成光环、结果卡入场和数字依次变化效果。
- 快速任务正常完成后补足约 3 秒的展示节奏，真实处理时间计入其中。
- 提前结束时明确显示工作已经完成，可点击“立即查看结果”跳过动画。
- 系统关闭动画、取消或处理失败时不增加展示等待；所有结果仍按实际测量显示。

## 修复与更新兼容

- 合并高频下载进度通知，固定提示区域，减少下载过程中界面闪烁。
- 默认更新来源切换至新仓库，兼容已保存的旧官方来源，保留自定义来源和指定分支。
- 更新仍采用后台下载并校验、询问用户后安装的流程。

## 升级说明

- 保留 `CleanSweep.exe`、原数据目录、隔离区和服务标识，兼容已有安装与更新流程。
- 解压 ZIP 后运行 `CleanSweep.exe`；界面和产品名称已是 FatalCleaner。
- 本包为 Windows x64 自包含版本，无需另行安装 .NET。
- 旧快捷方式或已登记的系统显示名称可能保留；程序文件中的图标已更新。
- 规则库仍为 v6，指纹库及弹窗规则仍为 v5。
