# FatalCleaner v0.25.0

本次优先修复开发依赖误清理问题，并加入保守的构建产物与程序更新缓存管理。建议使用开发者缓存功能的用户升级。

## 修复开发依赖误清理

- 保护已识别的 NuGet、Maven、Gradle、Cargo 等依赖仓库、部分运行环境和工具链；禁止清理其中的文件或通过移动父目录绕过保护。
- 开发缓存至少需要手动确认，每次扫描后重新勾选；旧版标为“安全”的开发缓存请求不能直接执行。当前用户常用的自定义依赖环境变量也纳入保护。
- 扫描、实际执行与隔离移动均检查保护路径；保留旧签名规则兼容性，旧数据不能重新扩大清理范围。
- 开发者缓存隔离项及当前护栏识别的受保护依赖，不再自动到期或超额淘汰；仍可恢复或由用户明确永久删除。
- JetBrains 使用专用缓存规则，保留 Local History、配置和插件；开发者页与应用缓存页使用一致的专用条目。

## 新增 .NET 构建产物预览

在设置中添加项目根目录后，开发者缓存页可识别具有项目文件、还原记录与生成清单的 bin/obj 产物。只列出至少 24 小时未修改、归属明确的生成文件，默认不勾选，逐文件移入隔离区。

检测到构建、编译、测试或开发环境进程时保守跳过；执行前再次核对当前范围、依据和进程。源码、普通配置、未知文件及生成依据保留。

## 新增程序更新缓存管理

设置 → 更新与记录 → 程序更新缓存，可预览超过 7 天的已过期更新文件和未完成下载，手动选择后移入隔离区。

保留待安装/较新版本、未知文件及恢复目录；索引损坏或无法确认时保留缓存。下载、索引读写和缓存维护使用同一文件锁，防止互相干扰。

## 下载与升级

- 首次使用可下载单文件 `FatalCleaner.exe`，保持免安装。
- 旧客户端继续通过 `FatalCleaner-win-x64-0.25.0.zip` 自动更新；原有设置、隔离区和服务身份沿用。
- 本版本防止已识别路径再次误清理，不会自动恢复此前已永久删除的依赖。若构建报缺包，应按原项目版本还原依赖。
- 自定义工具配置中的任意仓库位置并未全部覆盖；开发缓存不能视为零风险操作。

验证：本地完整验证结果与源码 CI、正式附件核对结果见同版本发布验收。真实多用户/UAC/SYSTEM 服务、断电恢复及 ARM64 不在本轮验收范围。
