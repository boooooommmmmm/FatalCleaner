# FatalCleaner v0.25.1

本次修复 v0.25.0 发布后复审发现的两项清理保护问题。

## 隔离区保留保护

- 自动到期与容量维护保留其他用户、归属不明的隔离项，避免切换管理员后使用错误的用户环境判断历史依赖。
- SYSTEM、LocalService、NetworkService 不自动淘汰隔离记录；用户仍可通过原有授权入口显式恢复或永久删除。
- 从隔离元数据重建索引后，同样执行归属保护。当前用户普通缓存的到期/容量维护保持可用，开发缓存与已识别依赖继续保留。

## 构建产物重新确认

- .NET 构建产物每次扫描均不勾选，不恢复旧版已保存的选择。
- 同一个项目重新构建、更改 DLL 或新增输出后，需要重新选择；其他普通清理项仍可记住勾选。

## 下载与升级

- 新用户下载 `FatalCleaner.exe`，单文件免安装。
- 旧客户端继续通过 `FatalCleaner-win-x64-0.25.1.zip` 更新；保留原有设置、隔离区和服务路径。
- 本版本不会恢复此前已永久删除的依赖。发生构建缺包时，仍需按原工程版本还原。

实际验证结果见同版本发布验收；跨用户保护使用隔离目录和模拟身份验证，真实 UAC/SYSTEM 服务、多用户 ACL、断电及 ARM64 未现场验收。
