## 证据与边界

证据根：`artifacts/verification/release-v0.24.0/`。

- `package/`：统一验收及 TRX。
- `legacy-signed-release-result.json`：旧客户端原公钥验证正式 ZIP。
- `legacy-upgrade/result.json`：模拟替换与实际 EXE 自检。
- `assets.json`、`public-verification.json`、`published.json`：附件与公开下载。
- `endpoints.json`、`endpoint-0.json`～`endpoint-3.json`：直连与镜像清单。
- `old-archives.json`、`local-cleanup.json`：旧包远端核对与删除明细。

未执行真实 UAC 切换账户、SYSTEM 服务替换、断电恢复或 ARM64 验收。模拟服务及普通单元测试不替代这些场景。
