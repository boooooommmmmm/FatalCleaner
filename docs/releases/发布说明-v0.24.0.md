# FatalCleaner v0.24.0

## 单文件免安装版

- 新增 `FatalCleaner.exe`：下载后直接运行，无需安装 .NET 或解压 ZIP。
- 程序内置运行时、清理规则、软件指纹及弹窗规则；内置和在线规则继续校验签名。
- 单文件版后续更新只替换自身，保留同目录的其他文件。
- 单文件版需要管理员权限时，可使用“以管理员身份重新启动”；不自动安装后台服务。

## 旧版本升级兼容

- 原来的 `CleanSweep.exe` 继续通过签名 ZIP 原位更新，保持已有快捷方式及提权服务路径。
- 设置、白名单、清理记录、隔离区及备份沿用原数据目录。
- 对于没有安装清单的旧版本，保留无法确认归属的文件，避免误删同目录的用户文件。
- 更新过程继续验证版本、签名、文件大小及哈希，替换失败时回滚。

## 开机加速状态更清晰

- 启用项显示浅绿整行背景，禁用项显示灰蓝整行背景，并保留文字状态标签。
- 禁用按钮采用橙色，启用按钮采用绿色；选中和悬停使用边框提示，保持原有状态底色。
- 服务项继续按“自动启动 / 非自动”和“设为自动 / 改为手动”区分。

## 下载选择

- **首次使用、免安装运行**：下载 `FatalCleaner.exe`，保留该文件名。
- **已有安装、提权服务或旧版自动更新**：使用 `FatalCleaner-win-x64-0.24.0.zip`，入口仍为 `CleanSweep.exe`。

本次发布 Windows x64。单文件指分发形式，运行时可能按需解出原生组件，设置与隔离文件仍正常持久保存。规则库 v6、指纹库 v5、弹窗规则 v5。
