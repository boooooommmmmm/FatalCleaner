## 证据与限制

本地证据根：`artifacts/verification/release-v0.25.0/`。

- preflight/、package/：统一验收摘要和 TRX。
- source-commit.txt、ci.json：构建提交及 GitHub 检查结果。
- legacy-signed-0.23.1-result.json、legacy-signed-0.24.0-result.json：旧版本原公钥验签。
- legacy-upgrade/result.json：模拟升级与实际 EXE 自检。
- assets.json、published.json、public-verification.json、public-portable.txt：正式附件及匿名下载验证。
- endpoints.json：客户端入口核对结果。

未执行真实 UAC/SYSTEM 服务替换、多用户配置、安装断电恢复或 ARM64 验收。已识别路径的保护不代表任意工具自定义仓库均已覆盖。此前永久删除的包需按原项目版本恢复；本版本不会自动补回用户机器上的依赖。
