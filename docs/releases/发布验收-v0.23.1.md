## 使用与边界

Windows x64 自包含 ZIP，解压运行 `CleanSweep.exe`。软件内可通过“设置 → 更新与记录”检查更新。保留原内部文件名、数据目录及新品牌图标。

未在本机禁用实际启动项或修改服务；相关界面测试使用模拟数据。未执行真实 UAC、SYSTEM 升级、安装回滚、断电和 ARM64 验收。此次未发布 Inno Setup 安装器；Windows 代码签名证书仍待配置，ECDSA 数据/发布清单签名已具备。
