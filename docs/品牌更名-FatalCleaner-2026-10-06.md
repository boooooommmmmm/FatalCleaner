# FatalCleaner 品牌更名

日期：2026-10-06。用户确定正式名称为 **FatalCleaner**，原名 CleanSweep。本次是本地开发，尚未提交或发布，公开版本仍为 v0.22.0。

## 更名范围

- 主窗口、侧栏、一键优化首页品牌字样、消息框和提权提示。
- 清理结果 JSON、操作日志 CSV 的默认导出文件名。
- 程序和服务的产品名、文件描述及公司元数据；新建服务、还原点与延迟任务的显示说明。
- PowerShell 安装脚本的快捷方式及卸载项显示名称；卸载脚本兼容两代快捷方式。
- Inno Setup 安装器名称、快捷方式和输出文件名。
- 后续发布脚本生成 `FatalCleaner-<RID>-<版本>.zip`，Release 标题使用 FatalCleaner。历史签名清单和已发布资产不修改。

## 兼容策略

继续使用 `CleanSweep.exe`、`CleanSweep.Service.exe`、原项目及命名空间。旧更新器依赖这些文件名，不能仅做全局替换。

保留原安装目录、用户/机器数据目录、隔离区目录、数据库、服务名、命名管道、单实例互斥锁、计划任务目录和所有权标记。Inno Setup 的 AppId、PowerShell 卸载注册表键以及更新来源保持原值。DelayDialog 继续准确显示任务计划程序中的 CleanSweep 文件夹。

已有快捷方式继续指向原可执行文件。新安装器使用新品牌；程序自更新仅替换程序文件，旧快捷方式或已登记的服务/卸载项显示名可能继续保留，重新运行对应安装入口后使用新名称。
