# 一键优化动画完善

日期：2026-10-03。当前为本地开发改动，尚未提交或发布；公开版本仍为 v0.22.0。

## 交互

- 点击后立即执行实际处理，同时播放旋转进度环，单圈 1.5 秒。
- 正常完成的快速任务，从开始到结果展示至少保留约 3 秒。实际处理时间计入其中；超过 3 秒的任务不再增加这段等待。
- 实际操作提前完成时显示“处理已结束，正在展示结果”，按钮切换为“立即查看结果”，可以跳过剩余动画。跳过不会把已经完成的操作标记为取消。
- 结果卡片以 650 毫秒的淡入和上移出现，四项大号数字依次延迟 0 / 100 / 200 / 300 毫秒，并在 650 毫秒内变化到实测值。
- 正常完成且确实处理了文件或成功执行内存操作时，进度环外播放约 1 秒的扩散光环。
- 系统关闭界面动画时，直接展示结果；任务取消、失败、未完成或请求的内存操作失败时，不补足等待时间。

## 数值和任务状态

沿用现有引擎结果，不增加模拟扫描或虚构收益。隔离量与直接释放磁盘空间仍分别展示，可用内存变化允许为负值，未知值显示横线；最近一次开机耗时不代表本次改善。没有处理文件且未执行成功的内存操作时显示“检查完成，暂无需要处理的文件”。

结果展示期间仍保持任务忙碌保护，防止另一次操作或安装更新重入；用户可跳过。实际工作完成后，迟到的进度回调不会覆盖结果展示状态。
