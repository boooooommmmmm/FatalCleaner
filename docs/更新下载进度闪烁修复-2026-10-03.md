# 更新下载进度闪烁修复

日期：2026-10-03。基于已发布 v0.22.0，修复在本地工作区，尚未提交或发布。

## 问题与处理

用户反馈检查更新后的下载进度变化会造成界面闪烁。检查发现：下载器每读取一块约 64 KB 数据就上报一次；原界面将每次回调投递到 UI 线程，同时改写可换行的侧栏状态文字，并让设置页刷新更新按钮状态。这些操作增加了界面刷新与布局次数。

- 增加 `CoalescingProgress`：第一条及时投递，后续按 100 毫秒周期合并；UI 队列最多保留一条待处理回调，回调读取最新样本。即使传输暂时停顿，最后一个样本也会按周期显示。
- 下载数字独立为 `DownloadProgressText`，侧栏只显示阶段状态，数字变化不再改写全局状态文字。
- 设置页只在忙碌状态、发布信息或阶段提示改变时同步更新按钮，不再响应每次字节数变化。
- 侧栏提示固定两行高度，完整文字保留在悬浮提示中；下载数字固定单行高度。
- 下载条使用单向数值绑定和实心填充模板，无主题扫光动画；保留真实数值进度和取消入口。
- 下载结束或取消后释放合并器，已排队的旧回调丢弃；现有来源代次检查仍生效。

下载、哈希和签名验证、失败重试、下载后询问安装的流程没有改变。未修改 Core、规则或发布版本。
